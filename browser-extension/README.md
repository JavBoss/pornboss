# JavBoss 助手

JavBoss 助手是一个 Chrome 扩展，用于连接 JavBoss 与第三方 JAV 网站。

## 功能

- **手动刮削回填**：在 JavBoss 视频刮削设置中选择“手动刮削”，打开 JavBus、JavLibrary、JavDB 或 AVSOX，完成网站验证并进入影片详情页后，点击“回填到 JavBoss”，返回 JavBoss 检查并保存。
- **JavDB 辅助跳转**：在 JavBoss 的作品、女优、系列或片商卡片中点击 JavDB 链接，直接进入对应详情页。默认开启，关闭后进入搜索页。
- **显示已拥有状态**：在 JavDB、JavBus、JavLibrary 的影片列表和详情页显示“已拥有”标记，默认开启。影片需关联未删除的视频文件记录，且所在目录未删除；仅有元数据或收藏记录不算拥有，目录停用或暂时离线不影响判断。
- **磁力下载**：开启“启用磁力下载”后，在网页点击磁力链接，确认即可提交到 JavBoss 下载队列。需先在 JavBoss 的“下载”→“下载设置”中配置 CloudDrive2 和本地下载目录。

## 连接设置

“显示已拥有状态”和“磁力下载”需要连接 JavBoss：

1. 在 JavBoss 的“全局设置”→“安全”→“浏览器扩展 API 令牌”中新建令牌并复制。
2. 点击浏览器工具栏中的“JavBoss 助手”，在“连接设置”中填写 Server 地址和 API 令牌，点击“测试连接”。Server 地址填写实际访问 JavBoss 的 HTTP 或 HTTPS 地址。
3. 按需开启功能，设置修改后自动保存。仅查询已拥有状态无需启用磁力下载。

请同步更新 JavBoss 和扩展以使用新功能。连接异常时，检查 Server 地址及令牌是否有效，测试连接后刷新目标网页。
